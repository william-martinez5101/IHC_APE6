1. William publica el informe y la organización primero.
2. Cada persona acepta su invitación de colaboración si aún no lo hizo, actualiza main y crea la rama indicada.
3. Revisa su parte, crea los dos commits sugeridos y hace push desde su cuenta. No cambiar identidades Git para aparentar otra persona.
4. Crear pull request hacia main y solicitar revisión cruzada. William coordina la integración.
5. Preservar autorías de los cinco aportes al integrar. Verificar atribución real en GitHub, no solo el nombre configurado en Git local.
6. Después de integrar, ejecutar el script de historial y enviar a Moodle el PDF y el enlace.

```bash
python APE6_FASE1/colaboracion/verificar_autorias.py
```
