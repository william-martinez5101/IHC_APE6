# Verificación reproducible

Ejecutar desde cualquier carpeta:

```bash
python Fase2-Pilotaje/Verificacion/verificar_metricas.py
```

Solo requiere Python 3 y su biblioteca estándar. Recalcula las métricas desde Datos/participantes_anonimizados.json y las contrasta con los resúmenes. Verifica 3 × 6 tareas y 5 × 10 heurísticas. Estas comprobaciones son de cálculo y estructura; no representan nuevas sesiones de usuarios.
