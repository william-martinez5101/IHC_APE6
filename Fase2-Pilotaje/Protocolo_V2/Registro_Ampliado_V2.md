# Campos de aplicación de V2

El estado inicial, resultado, tiempo, errores, frases y SUS conservan la definición de V1. Para una ronda posterior añadir: tarjeta consultada (Sí/No); contenido final correcto (Sí/No); estado de guardado/punto de detención correcto (Sí/No); motivo de pista (petición/bloqueo/no aplica); momento del último avance; preparación validada por soporte y observador; pausa y duración si ocurrió. Estos campos no se rellenan con inferencias sobre las sesiones V1.

Las observaciones se registran cuando ocurren. No aplica se usa solo cuando el campo no corresponde; no registrado identifica información que debió medirse y no se obtuvo.
